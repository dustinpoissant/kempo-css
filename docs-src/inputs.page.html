<select
  readonly
  class="mb"
>
  <option>Read only select</option>
</select>

<select
  multiple
  readonly
  class="mb"
>
  <option>Read only option 1</option>
  <option selected>Read only option 2</option>
  <option>Read only option 3</option>
</select>

<input type="checkbox" readonly checked id="ro-check" />
<label for="ro-check" class="checkbox">Read only checkbox</label>

<input type="radio" name="ro-radios" readonly checked id="ro-radio" />
<label for="ro-radio" class="checkbox">Read only radio</label>
<input type="radio" name="ro-radios" readonly id="ro-radio-2" />
<label for="ro-radio-2" class="checkbox">Read only radio 2</label>


Browsers do not support readonly on a select, checkbox or radio. kempo-css blocks mouse input on them with pointer-events: none, but keyboard users can still focus and change them. To block that too, prevent changes in script.
